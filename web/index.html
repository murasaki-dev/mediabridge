Playback defaults

Uses the selected browser's local profile through yt-dlp. MediaBridge does not access your YouTube account through OAuth. On Windows, Chromium browsers can lock their cookie database while open; fully quit the browser and retry if the error says it could not copy the database. You can keep this dashboard open on another device while doing that. A DPAPI decryption error is different and will not be fixed by closing the browser; try a Firefox profile signed into YouTube or another supported cookie source.

Server port

Applying a different port restarts MediaBridge and moves this dashboard to the new address. If you connect from another device, allow the new port through the host firewall. On Windows, update the MediaBridge Server firewall rule to the new port.
