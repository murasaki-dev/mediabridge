Connect your accounts

On the MediaBridge computer, use the sign-in buttons to open the persistent browser profile without playback automation. This closes the dashboard and stops current playback. After signing in, close LibreWolf and reopen the dashboard, then check whether each site's cookies can be read. YouTube can also report the active channel and profile picture. Twitch currently confirms that its sign-in cookie is present; it cannot verify the session or identify the account yet.

Server port

Applying a different port restarts MediaBridge and moves this dashboard to the new address. If you connect from another device, allow the new port through the host firewall. On Windows, update the MediaBridge Server firewall rule to the new port.
